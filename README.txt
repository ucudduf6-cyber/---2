LUMIO — GitHub Pages + Supabase

1. Загрузите index.html, cloud.js, config.js и папку assets в корень репозитория GitHub Pages.
2. Создайте проект Supabase. В SQL Editor выполните database.sql. Если политики уже существуют, не запускайте SQL повторно без проверки.
3. В Supabase Authentication → URL Configuration добавьте точный адрес вашего GitHub Pages сайта в Redirect URLs; укажите Site URL.
4. В Supabase Authentication включите Email (и подтверждение email). Настройте SMTP для реальной доставки писем.
5. В config.js заполните URL проекта и PUBLIC ANON KEY (или publishable key). Никогда не добавляйте service_role/secret key.
6. Опубликуйте сайт, зарегистрируйтесь на нём с адресом администратора и подтвердите email.
7. В Supabase SQL Editor выполните:
   insert into public.admins(user_id) select id from auth.users where email='ВАШ_EMAIL';
8. Для переноса первоначальных фильмов из демоверсии: войдите администратором, откройте DevTools Console и вставьте содержимое seed-catalog.js. На мобильном устройстве удобнее выполнить это на компьютере. Либо добавьте фильмы через админку.
9. Теперь фильмы, загруженные постеры/трейлеры и отзывы доступны всем устройствам. Отзывы показываются публично только после публикации модератором.

Ограничения:
- Supabase Free может ограничивать размер одного загружаемого файла (в частности, большой трейлер). Для больших файлов используйте внешний видеохостинг и вставьте ссылку в админке.
- Обязательно проверьте права на публичный показ видео, постеров и трейлеров.
- Документы «Политика конфиденциальности» и «Соглашение» требуют реквизитов оператора, контактов, условий обработки email и данных Supabase до коммерческого запуска.
- Ссылки на страницы VK/Кинопоиска нельзя автоматически использовать как файл постера без доступного прямого URL или API.
- GitHub Pages не предоставляет backend. Без настройки Supabase регистрация, общие отзывы, админка и загрузки не будут работать.


НОВОЕ В v7:

- Профиль → Добавить фильм/сериал → заявка на модерацию → администратор публикует или отклоняет.

- Контактные адреса .example — заглушки, перед публикацией замените на рабочие.
- Политика и соглашение — шаблоны, требуют проверки юристом.
- Полная проверка на реальном Supabase и GitHub Pages не выполнена.
